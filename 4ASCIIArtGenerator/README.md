# 🇬🇧 English

## 📌 About

This project is a modern ASCII Art Generator built with Python and Tkinter.

The application allows users to:
- Select an image
- Convert it into ASCII art
- Preview the original image
- Save the ASCII result as a text file

---

## 🚀 Features

✅ Modern dark GUI  
✅ Image preview  
✅ ASCII art conversion  
✅ Save ASCII art as TXT file  
✅ Beginner-friendly Python project  
✅ Desktop application with Tkinter

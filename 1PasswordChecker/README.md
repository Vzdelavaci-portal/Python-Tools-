# 🔐 Python Password Strength Checker

# 🇬🇧 English

A simple Python GUI application that checks password strength in real time.

Built with:
- Python
- Tkinter

---

## 🚀 Features

✅ Real-time password strength checking  
✅ Modern 9:16 GUI design  
✅ Color strength indicator  
✅ Visible password input  
✅ Checks:
- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

---

## ▶️ Run the Project

```bash
python password_strength_checker.py
```

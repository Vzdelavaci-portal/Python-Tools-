# 💼 Python Business Card Generator

CZ 🇨🇿 / EN 🇬🇧

Modern Python GUI application for generating stylish business cards.

Moderní Python GUI aplikace pro generování stylových vizitek.

---

# 🇬🇧 English

## 📌 About

This project is a modern business card generator built with Python and Tkinter.

Users can:
- Enter their personal information
- Generate a professional business card
- Preview it instantly inside the application
- Save it as a PNG image
- Print the business card directly

---

## 🚀 Features

✅ Modern dark GUI  
✅ Live business card preview  
✅ Stylish business card design  
✅ Save as PNG image  
✅ Print business card  
✅ Beginner-friendly Python project  
✅ Desktop application with Tkinter

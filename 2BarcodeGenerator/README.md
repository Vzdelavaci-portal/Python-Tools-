# 🏷️ Python Barcode Generator GUI

CZ 🇨🇿 / EN 🇬🇧

Simple Python GUI application for generating and previewing barcodes.

Jednoduchá Python GUI aplikace pro generování a zobrazení čárových kódů.

---

# 🇬🇧 English

## 📌 About

This project is a modern Python barcode generator with a GUI interface.

Users can enter text or numbers, generate a barcode and instantly preview it directly inside the application.

---

## 🚀 Features

✅ Modern GUI design  
✅ Generate barcodes from text or numbers  
✅ Live barcode preview inside the app  
✅ Saves barcode as PNG image  
✅ Beginner-friendly Python project  
✅ Desktop application built with Tkinter

---

## 🛠 Technologies

- Python
- Tkinter
- python-barcode
- Pillow

---

## 📦 Installation

Install required libraries:

```bash
pip install python-barcode pillow
```

---

## ▶️ Run the Project

```bash
python barcode_generator_gui.py
```
